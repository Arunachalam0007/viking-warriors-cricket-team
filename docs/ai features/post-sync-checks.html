AI feature

Post-sync data checks

Exact, rule-based checks of the data after each sync, with a short AI summary of what to look at first.

Purpose and access

read Admins: full list on Admin → Sync & logs; warnings only on Revenue overview. Each row links to the page where it is fixed. The checks run on every page view (no AI); the AI only writes the summary paragraph.

Checks

CheckSeverityFix it in
Fixture dated before today but never scoredinfoCricHeroes (score or delete); the next sync updates it
Played match with no players recordedwarnMatch fees → the match
Members who played ≠ match fees charged (chargeable matches without any waived / edited fee)warnMatch fees → the match
Guest who played 3+ matches this seasoninfoManage players → mark as member
Two players with the same nameinfoManage players
Members owing 6 × match fee or moreinfoDues reminders
Last CricHeroes sync failed / had warningswarn / infoSync & logs

Flow

flowchart LR
  S[Sync helper: CricHeroes sync] --> J["runAiJobs()"]
  J --> K["runSyncChecks() (checks.ts)"]
  K -- "checks changed" --> G["AI summary (bulk chain) → ai_content sync_check/latest"]
  P[Admin → Sync & logs] --> K2["runSyncChecks() live"]
  P --> T[(ai_content summary)]
