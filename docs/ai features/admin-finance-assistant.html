AI feature

Admin finance assistant

AI-Viking-Bot in Admin mode answers money questions from the full ledger: who owes what (with phone numbers), collections against expenses, money per cash holder, fees per match.

Purpose and access

read Admins only: the Admin switch appears in the chat header for logged-in admins, and /api/ai/chat refuses mode: "admin" (403) without an admin session. Admin chats are a separate conversation from Team chats.

Architecture

flowchart LR
  A[Admin in chat: Admin mode] --> R["/api/ai/chat mode=admin"]
  R --> V{"getViewer().isAdmin?"}
  V -- no --> X[403]
  V -- yes --> S["streamText: public tools + admin tools (chat chain)"]
  S --> Q[finance/queries.ts: getRevenueSummary, getPlayerBalances, getChargeRows, getMatchFinanceSummaries]
  S --> E[payments, expenses, income, cash holders]
  S --> C[checks.ts: runSyncChecks]

Admin read tools

ToolReturns
financeOverviewCharged, collected, outstanding, credit, income, expenses, fund balance, per cash holder, per month
balancesEvery player's charged / paid / balance, match-fee count, phone
chargesCharges by month, match, player or status (up to 80 rows + totals)
matchFeesPer played match: chargeable, fee, players charged, paid, due
paymentsPayments by player / month with mode, holder, reference
expensesAndIncomeExpenses and other income, optional month
dataChecksThe post-sync checks
findPlayerByNameSearch by part of a name

Plus all public tools, with balances always visible to admins. The system prompt lists the cash holders (Rahul by default).

Example questions

  • Who owes the most? List with phone numbers.
  • Collected vs expenses this month.
  • How much cash does each holder have?
  • Which matches in October still have unpaid fees?
  • அக்டோபர் மாசம் எவ்வளவு collect ஆச்சு?
