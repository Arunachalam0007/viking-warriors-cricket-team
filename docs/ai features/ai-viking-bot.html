AI feature

AI-Viking-Bot chatbot

An animated chat assistant on every page. Players ask about fixtures, results, stats, the leaderboard and match-fee dues, in Tamil, Tanglish or English, by typing or speaking.

Purpose and access

read Everyone (when ai_public_chat is on). Admins also get an Admin mode switch (see finance assistant). Answers come only from the database through tools.

What is on screen

  • Launcher: round team-gradient button with the logo, a turning colour ring, a pulse and a sparkle; a “AI-Viking-Bot 🏏 கேளுங்க!” bubble once per visit. Bottom-right, above the phone menu.
  • Panel: springs open from the button; a card on desktop/tablet (420 × up to 680 px), full screen on phones (page behind stops scrolling). Header: logo with online dot, “Typing…” while answering, தமிழ் / English / Auto answer language, Team / Admin (admins), New chat, Close (Esc).
  • Welcome: logo with an orbiting cricket ball, வணக்கம்!, suggestion chips (plus “this match / this player” chips on match and player pages).
  • Messages: user bubbles in team gradient; answers in markdown (bold, lists, tables) with links to player and match pages; tool chips (“Checking the leaderboard…” with a spinning ball, then ✓); bouncing cricket balls while thinking; a blinking caret while streaming.
  • AI loader: while the bot looks things up, a card with a spinning team-colour orb (cricket ball in orbit), the current step in shimmering text (“Checking the leaderboard…” / “Leaderboard பார்க்கிறது…”) and placeholder lines where the answer will appear.
  • Under each answer: Copy, Read aloud (spinner while the voice is prepared, equaliser while it plays, tap again to stop), and “via Gemini / via Groq”.
  • Composer: grows to 5 lines; Enter sends, Shift+Enter new line; mic for voice input (ta-IN, or en-IN when English is chosen; hidden where the browser has no speech recognition); Send turns into Stop while answering.
  • Errors: friendly message with Retry; limits explain when to try again.
  • Language switch: தமிழ் = Tamil answers, suggestions, labels, tool chips, Confirm cards, Tamil voice input (ta-IN) and Tamil read-aloud; English = all English (en-IN voice); Auto = suggestions alternate Tamil and English, the answer follows the question's language, and read-aloud follows the answer's language. The choice is remembered in this browser.
  • The conversation is kept in this browser only (localStorage, last 30 messages, separately for Team and Admin).

Read-aloud voice

Phones and laptops rarely have a Tamil voice installed (iPhones have none), so the browser would read Tamil in an English voice. The audio is made on the server instead: POST /api/ai/speak with the answer and its language.

OrderServiceVoice
1Microsoft Edge read-aloud (free, no key; the answer text is sent to Microsoft)Tamil: ta-IN-PallaviNeural · English: en-IN-NeerjaNeural
2Gemini text-to-speech (free tier, GEMINI_API_KEY): gemini-3.8-flash-tts → gemini-3.1-flash-tts-preview → gemini-2.5-flash-preview-ttsKore
3The device's own voice (only if both fail)ta-IN / en-IN

Language: தமிழ் always Tamil, English always English, Auto follows the answer's script. Markdown is turned into plain sentences first (links → names, tables → lines, max 1,800 characters). Each answer's audio is kept in the browser for the visit, so a replay is instant. Calls are logged in ai_usage as feature speech.

Prompt rules

  • Look everything up with tools; never answer stats or money from memory.
  • Answer in the user's language (Tamil script or Tanglish → Tamil), or the chosen one.
  • Short answers for phones; markdown; link players and matches with the urls tools return.
  • Only Viking Warriors topics.
  • The current page is passed in, so “this match” / “this player” work.

Limits

No question limit (owner's decision): when Gemini's free quota is used up, questions are answered by Groq, and the other way round (fallback). Neither free tier bills. Questions are still counted (one ai_usage row with model question and a salted hash of the visitor's IP) for Admin → AI.
