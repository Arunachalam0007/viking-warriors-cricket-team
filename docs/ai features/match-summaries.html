AI feature

AI match reports

A short, lively report of every played match, in Tamil and English, ready to paste into the team WhatsApp group.

Purpose and access

read Everyone sees it on the match page as a card with a Tamil / English switch (Tamil first, choice remembered) and a Copy-for-WhatsApp button. Admins can edit, hide or rewrite it in Admin → AI.

How it is written

flowchart LR
  T["Trigger: sync helper after each sync · nightly cron (8 texts) · Admin → AI 'Update now' · npm run ai:jobs"] --> J["runAiJobs()"]
  J --> F["matchFacts(matchId) (facts.ts)"]
  F --> H{"facts hash changed? edited?"}
  H -- "new or changed, not edited" --> G["generateText + Output.object (bulk chain)"]
  G --> S[("ai_content: match_summary, match id, ta + en")]
  H -- "same facts or admin-edited" --> K[skip]
  S --> P["the match page reads it (no AI call on page view)"]
  1. Facts: date, opponent, type, ground, overs, result, both scores, player of the match, batting (runs, balls, 4s, 6s, dismissal), bowling (overs, wickets, runs, maidens), fielding, top-3 MVP.
  2. Brief: “70–110 words: result first, then standout batting and bowling with exact figures and the player of the match.”
  3. One call writes the English and Tamil versions (structured output: title_en, body_en, title_ta, body_ta). Team name: Viking Warriors in English, வைகிங் வாரியர்ஸ் in Tamil.
  4. Both rows are upserted with the facts hash, provider and model; an admin-edited row is left alone (setWhere edited = false).

Rules and edge cases

  • Written only from facts; the prompt forbids invented numbers.
  • A corrected scorecard changes the facts hash, so the text is rewritten at the next run.
  • Hidden texts are not shown anywhere; “Write again” releases an admin edit and rewrites it.
  • A run writes at most 25 texts (8 on Vercel within 35 s); the rest follow next time.
