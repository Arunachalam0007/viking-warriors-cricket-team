AI feature

Dues reminder drafts

Friendly WhatsApp reminders for every member who owes match fees, in Tamil and English, with the exact amount, the unpaid matches and Ragul's GPay number. The admin sends them one tap at a time; nothing is sent automatically.

Purpose and access

read write Admin → Dues reminders. No WhatsApp API, no cost, no risk to the number: each message opens in the admin's own WhatsApp (phone app, WhatsApp Desktop or Web) with the text ready, and the admin presses Send.

On the page

  1. GPay number in the messages: name (default Ragul) and GPay number, saved in settings gpay_name / gpay_number. Printed as “💵 Pay Ragul by cash or GPay: 98765 43210” in every reminder and the group summary; if it is empty, the mobile number on Ragul's player record (Ragul RD) is used. Only in messages admins send, never on the public site or in the public chat. Without a number the line says “pay Ragul by cash or UPI”.
  2. Who owes: every member with a balance, with “Reminded 4 Nov” / “Not reminded yet”. Players reminded in the last 7 days start unticked. Tone: Friendly or Firm but polite. Draft writes all messages.
  3. Send all: a step-by-step dialog, “3 of 19 · 2 sent”, Tamil / English switch, editable text. Send on WhatsApp opens that player's chat with the message and records it as sent; the next player is ready when the admin comes back. Back and Skip.
  4. Drafts: one card per player (edit, Send on WhatsApp, Copy, Mark as sent).
  5. Team group summary: one message with everyone's dues, the total and the GPay line; Share to WhatsApp group opens WhatsApp's chat picker.
  6. Phone numbers: the whole squad in one list, one Save. 10-digit numbers get +91 in the WhatsApp link.
  7. Recently sent: the last 30 reminders opened in WhatsApp.

Admin → Revenue overview shows “Dues reminders not sent this week” when members owe and no reminder went out in 7 days.

How a message is built

flowchart LR
  L[(Ledger: balance + unpaid match fees)] --> C[composeReminder]
  S[(settings: gpay_name, gpay_number, upi_id)] --> C
  A["AI (chat chain): one opening sentence per player, ta + en, no numbers"] --> C
  F[Fixed opening if the AI is unavailable] -.-> C
  C --> M["வணக்கம் *Yogi*! 🏏 / opening / *Match fee பாக்கி: ₹150* / • 1 Nov vs K K Guys – ₹50 … / 💵 Pay Ragul by cash or GPay: *98765 43210* / thanks / — வைகிங் வாரியர்ஸ்"]
  M --> W["wa.me/91XXXXXXXXXX?text=…"]
  W --> O[(notification_outbox: status sent, sent_at)]

The AI writes only the friendly opening line and is told not to mention amounts; the greeting, amount, match list (up to 8, then “and N more”), GPay line and sign-off are filled in by the app, so the numbers are always exact. An opening that contains ₹ or long numbers is replaced by the fixed one.
