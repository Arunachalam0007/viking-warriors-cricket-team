AI feature

Plain-language admin edits

Admins type what to change (“Mark Yogi and Gopi paid for 1 Nov, UPI”); the assistant finds the match and players and shows an exact preview card. Nothing changes until the admin taps Confirm.

Purpose and access

write Admins only, in AI-Viking-Bot Admin mode. Every change runs like a normal admin edit: one transaction, audit entry with the admin as actor (ai.* actions), Google Sheet refresh.

Confirm flow

  C->>R: message
  R->>M: tools
  M->>R: matches / listPlayers (read)

  T->>D: needsApproval: read what would change

  T-->>C: approval-requested → Confirm / Cancel card
  alt Confirm
    A->>C: Confirm
    C->>R: approval (auto-sent)
    R->>T: execute (admin session checked again)
    T->>D: transaction + audit ai.match.mark_paid
    T-->>C: Saved ✓ + one-line answer
  else Cancel
    A->>C: Cancel
    C->>R: denial
    R-->>C: "Okay, cancelled. Nothing was changed." (no model call)
  end

Safety

  • The preview is built by the server from the database, not written by the AI, so the names and amounts on the card are exactly what will be saved.
  • Unknown ids or nothing-to-change skip the Confirm card and report the problem (“No player with that id”, “Nobody has an unpaid fee…”).
  • Cancel is answered by the server without the model, so the assistant cannot propose the same change again by itself.
  • Ledger rules are unchanged: the tools call the same ledger.ts functions as the admin pages.
