Public page

Dashboard

The home page: team record, next fixture, recent results, this month's top performers and match-fee totals.

Purpose and access

public

Open to everyone; no login. Pages are rendered on the server on every request from the app database (never from CricHeroes directly).

URL and query parameters

URL / parameterMeaning
/No parameters.

What is shown

  • Header — team name (setting team_name) and "since" date (sync_start_date).
  • Record tiles — Played, Won (with win % of decided matches), Lost, Abandoned / other (getTeamRecord).
  • Next fixture — the earliest non-past match: opponent and logo, date/time (IST), ground, tournament name.
  • Match fees — Charged, Collected, Due across all charges, with a link to Finance.
  • Recent results — last 5 past matches with scores and Won/Lost badge, linking to match detail.
  • Top performers · current month — top 3 by MVP points this IST month (runs, wickets, catches shown).
  • Footer line — total owed by team members (sum of positive balances).

Rules and edge cases

  • Months and "this month" are IST (istMonth, monthDateRange).
  • Win % uses won / (won + lost); abandoned and no-result matches are excluded.
  • An upcoming match is any match whose status is not past (upcoming or live).
