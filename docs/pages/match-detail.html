Public page

Match detail

Scorecard summary for our XI with MVP points, player of the match and the match-fee status of every player.

Purpose and access

public

Open to everyone; no login. Pages are rendered on the server on every request from the app database (never from CricHeroes directly).

URL and query parameters

URL / parameterMeaning
/matches/[id]id = matches.id. Unknown ids show not-found.

What is shown

  • Header — opponent, date/time, ground, scores, result text, type or tournament, CricHeroes scorecard link.
  • Player of the match — when pom_cricheroes_player_id matches someone in our XI.
  • Batting — runs, balls, 4s, 6s, strike rate, dismissal.
  • Bowling & fielding — overs, maidens, runs, wickets, economy, catches / stumpings / run outs, MVP points.
  • Match fees — each charged player with amount and status badge, totals (hidden per-player when public_show_balances is off).
