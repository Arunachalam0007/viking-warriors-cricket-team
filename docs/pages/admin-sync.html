Admin page

Sync & logs

Run the CricHeroes sync and Google Sheet rebuild on demand, and review the sync history and the audit trail.

Purpose and access

admin only

Admins only. proxy.ts redirects anonymous visitors to /login; the page calls requireAdmin() before loading data, and every action re-checks through adminAction().

URL and query parameters

URL / parameterMeaning
/admin/syncNo parameters.

What is shown

  • CricHeroes card — last run / last success, Sync CricHeroes now with the returned summary: matches seen / new / updated, scorecards fetched, new players, charges created / removed, warnings.
  • Google Sheet card — last run, Rebuild Google Sheet now.
  • Sync history — last 40 runs: kind, trigger (cron / manual / change), start time (IST), duration, status, summary or error.
  • Audit log — last 100 admin changes: when, who, action, entity, expandable before / after JSON.
  • Note: the nightly job runs at 23:30 IST.
