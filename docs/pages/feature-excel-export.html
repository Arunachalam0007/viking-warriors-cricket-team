Excel export

Download the finance view as a formatted .xlsx workbook.

Purpose and access

feature

URL and query parameters

URL / parameterMeaning
GET /api/export/financePublic workbook for all months.
month, from, to, matchId, playerId, status, kindSame filters as the Finance page (validated by parseFinanceFilter; invalid values dropped).
scope=adminAdmin workbook; requires an admin session, else 401.
