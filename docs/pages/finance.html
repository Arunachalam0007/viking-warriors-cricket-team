Public page

Finance

Public match-fee finance: who played, what each player owes and has paid, by month, match, player and status, with Excel export.

Purpose and access

public

Open to everyone; no login. Pages are rendered on the server on every request from the app database (never from CricHeroes directly).

URL and query parameters

URL / parameterMeaning
/financeAll months since finance_start_date (1 Oct 2026).
month=YYYY-MMCharges dated in that IST month. Changing it clears matchId.
matchId=&lt;uuid&gt;Only one match (options: past matches in the chosen month).
playerId=&lt;uuid&gt;Only one player (hidden when balances are not public).
status=due|unpaid|partial|paid|waivedCharge status; due = unpaid or part paid.
view=players|matches|chargesTab. Default players; forced to matches when balances are not public.

What is shown

  • Totals tiles for the filter: Charged (non-waived), Collected (allocated), Due.
  • By player — matches, charged, paid, due for the filter, plus overall balance; totals row. Cards on phones, table on larger screens.
  • By match — date, opponent, charged?, fee, players, charged, paid, due (getMatchFinanceSummaries).
  • All entries — every charge with player, description, amount, paid, due, status badge.
  • Pay via UPI bar with copy button when setting upi_id is set.
  • Export to Excel — downloads /api/export/finance with the same parameters (see Excel export).

Data flow

flowchart LR
  U["Visitor picks month / match / player / status"] --> URL["URL search params"]
  URL --> PG["finance/page.tsx validates params"]
  PG --> Q["getChargeRows(filter)"]
  Q --> V1["By player: summarizeByPlayer"]
  Q --> V3["All entries"]
  PG --> V2["By match: getMatchFinanceSummaries"]
  PG --> X["Export link with same params"] --> API["/api/export/finance"]

Rules and edge cases

  • Invalid parameter values are ignored (regex / UUID checks), never errors.
  • Due for a waived charge is 0; paid is capped at the amount.
  • Overall balance can be negative = credit (paid in advance).
  • Phone numbers, payment details, expenses and cash holders are never shown here.
