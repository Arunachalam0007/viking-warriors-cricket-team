Public page

Players

Grid of squad members with photos, then guests who have played. Each card opens the player profile.

Purpose and access

public

Open to everyone; no login. Pages are rendered on the server on every request from the app database (never from CricHeroes directly).

URL and query parameters

URL / parameterMeaning
/playersNo parameters.

What is shown

  • Squad members (is_member = true) as cards: photo, name, captain badge, batting / bowling category, matches, runs, wickets (all-time since sync start).
  • Guest players — non-members who appear in at least one stats row, shown smaller.

Database mapping

Rules and edge cases

  • Photo = admin-uploaded photo_url if set, else the CricHeroes photo, else initials.
  • Phone numbers are never shown on public pages.
  • Members come from the CricHeroes squad page; admins can switch member ↔ guest in Manage players.
