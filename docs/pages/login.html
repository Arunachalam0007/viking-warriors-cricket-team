Public page

Admin login

Email magic-link sign-in for admins, the Supabase callback, and sign out.

Purpose and access

public

Open to everyone; no login. Pages are rendered on the server on every request from the app database (never from CricHeroes directly).

URL and query parameters

URL / parameterMeaning
/loginLogin form. Already-signed-in admins are redirected to /admin.
/login?error=not_admin|link|googleError message: email not on the admin list / link expired or opened in another browser / Google unavailable.
/auth/callback?code=…&amp;next=/adminSupabase redirects here; the code is exchanged for a session (PKCE) and the user goes to next (only same-site paths).
POST /auth/signoutSigns out and returns to / (sidebar button).

Actions

  1. Admin enters their email → server action sendMagicLink validates it, checks admins (isAdminEmail), and calls supabase.auth.signInWithOtp with emailRedirectTo = SITE_URL/auth/callback?next=/admin.
  2. Admin opens the email link in the same browser → /auth/callback exchanges the code and sets cookies.
  3. /admin loads; requireAdmin() confirms the email is still in admins.
  4. Optional: "Continue with Google" (signInWithGoogle) when NEXT_PUBLIC_GOOGLE_AUTH_ENABLED=true.

Rules and edge cases

  • Team members never need to log in.
  • Supabase's default email sender allows only a few emails per hour; configure custom SMTP in Supabase if needed.
  • Locally without Supabase, DEV_ADMIN_EMAIL acts as the signed-in admin (development only).
