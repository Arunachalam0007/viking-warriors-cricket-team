Feature

Google Sheet mirror

The app writes its finance data into the team's Google Sheet, month-wise, after every change and every night.

How a write works (writeSheet)

  1. Read the spreadsheet id from setting google_sheet_url (sheetIdFromUrl).
  2. spreadsheets.get → add any missing tabs with one batchUpdate.
  3. values.batchClear on the managed tabs, then one values.batchUpdate with all grids.
  4. One batchUpdate to bold and freeze header rows (4 rows on month tabs).

Tabs the app does not manage are never touched. About 4–5 API calls per rewrite.

When it runs (syncSheet(trigger))

  • change — after every admin action, via after(). Waits 5 seconds; if a newer request arrived, this one is marked skipped, so a burst of clicks makes one write.
  • manual — Rebuild Google Sheet now (Sync & logs), and after Sync CricHeroes now.
  • cron — every night after the CricHeroes sync.

Rules and edge cases

  • Setup: share the sheet with GOOGLE_SERVICE_ACCOUNT_EMAIL as Editor. Otherwise the run fails with "Permission denied. Share the Google Sheet with … as Editor." (404 → "Google Sheet not found").
  • Not configured (no service account env or no sheet URL) → status skipped, nothing breaks.
  • Manual edits inside managed tabs are overwritten; the database is the source of truth.
