Feature

Nightly cron

The scheduled job that refreshes CricHeroes data and rebuilds the Google Sheet every night.

Purpose and access

feature

URL and query parameters

URL / parameterMeaning
GET /api/cron/nightlyRequires header Authorization: Bearer $CRON_SECRET; otherwise 401.

What is shown

// vercel.json
{ "regions": ["bom1"], "crons": [{ "path": "/api/cron/nightly", "schedule": "0 18 * * *" }] }

0 18 * * * = 18:00 UTC = 23:30 IST. On Vercel's Hobby plan the job runs once a day, at some point within that hour. Vercel sends the CRON_SECRET environment variable automatically.

  1. Check the secret.
  2. runCricheroesSync("cron") — errors are caught and reported.
  3. syncSheet("cron") — always runs, so admin edits are mirrored even if CricHeroes failed.
  4. Return JSON with both results; HTTP 500 if CricHeroes failed (visible in Vercel's cron logs).
