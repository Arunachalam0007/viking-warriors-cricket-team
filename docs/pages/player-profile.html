Public page

Player profile

One player's photo, role, career stats, recent matches and match-fee dues.

Purpose and access

public

Open to everyone; no login. Pages are rendered on the server on every request from the app database (never from CricHeroes directly).

URL and query parameters

URL / parameterMeaning
/players/[id]id = players.id (UUID). Unknown or malformed ids show the not-found page.

What is shown

  • Header — large photo, name, captain / member / guest badges, batting and bowling category, link to the CricHeroes profile (when cricheroes_player_id exists).
  • Summary tiles — matches, runs, wickets, MVP points.
  • Batting — innings, runs, average, strike rate, highest score (* = not out), 50s/100s, 4s/6s.
  • Bowling — overs, wickets, economy, best bowling (shown as "–" if the player has not bowled: bestRuns = -1), maidens.
  • Fielding — catches, stumpings, run outs.
  • Recent matches — last 20 matches played with figures and result.
  • Match fees & dues — overall balance (owes / credit) and every charge with its status badge. Hidden when setting public_show_balances is off.

Rules and edge cases

  • Average = runs / dismissals; with no dismissals it shows runs with an asterisk.
  • Overs are stored as balls (balls_bowled) and displayed as overs.balls.
