Public page

Matches

All synced matches since the sync start date, with filters for month and match type.

Purpose and access

public

Open to everyone; no login. Pages are rendered on the server on every request from the app database (never from CricHeroes directly).

URL and query parameters

URL / parameterMeaning
/matchesAll matches, newest first.
month=YYYY-MMOnly matches in that IST month.
kind=individual|tournamentOnly that match type.

What is shown

One card per match: date and time (IST), opponent logo and name, both scores, result badge (Won / Lost / Abandoned / Tied / No result / Upcoming), type badge (individual or tournament name), ground. Each card links to the match detail.

Rules and edge cases

  • Matches before sync_start_date (1 Oct 2026) are never imported.
  • Match type comes from CricHeroes (tournament name present → tournament) unless an admin changed it.
