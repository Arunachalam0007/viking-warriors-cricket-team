Admin page

Match fees

The core admin screen: per-month match list and a per-match editor for who played, fee settings, and paid / not paid / waived per player.

Purpose and access

admin only

Admins only. proxy.ts redirects anonymous visitors to /login; the page calls requireAdmin() before loading data, and every action re-checks through adminAction().

URL and query parameters

URL / parameterMeaning
/admin/fees?month=YYYY-MMPast matches of that month with charged / paid / due. Default: the month of the newest match.
/admin/fees/[matchId]Editor for one match (matches.id).

What is shown

Month list

Totals for the month and one row per past match: date, opponent, result, type, charged on/off, fee × players, charged / paid / due, link to the editor.

Match editor

  • Fee settings — Charge match fee (switch), Fee per player (₹), Match type (individual / tournament), Notes. Saving locks these from the nightly sync.
  • Players & fees — every player in match_players: avatar, name, member/guest, Played switch, amount (inline edit), status badge, Mark paid / Unpaid, Waive / Restore. Guests show "Not charged (guest)". Charges for players no longer marked as played but already paid or edited appear as "did not play" rows so they can be waived.
  • Add player who played — any player not in the roster.
  • Mark all paid — all unpaid fees of the match in one go, with payment options.
  • Totals — charged, paid, due.

Actions

Every action below is a server action wrapped by adminAction() (src/lib/action.ts): admin check → zod validation → one database transaction → audit_log entry → refresh() → Google Sheet rewrite after the response (after(() => syncSheet("change"))).

Data flow

sequenceDiagram
  participant A as Admin
  participant UI as RosterEditor
  participant S as setMatchPlayer
  participant L as reconcileMatchCharges
  participant D as Postgres
  A->>UI: switch Played off for a player
  UI->>S: matchId, playerId, played false
  S->>D: match_players played=false, admin_locked=true
  S->>L: reconcile match
  L->>D: delete unpaid unlocked fee (keep if paid or locked)
  S->>D: audit_log
  S-->>UI: ok, page refreshes

Rules and edge cases

  • Tournament matches are not charged unless an admin switches Charge match fee on (and may set a fee).
  • Changing the default fee in Settings never changes saved matches; set the fee here per match.
  • "Unpaid" on a charge paid from a lump sum turns that money into credit, which applyCredit may re-apply to the oldest open charge. To truly reverse, delete the payment on the Payments page.
