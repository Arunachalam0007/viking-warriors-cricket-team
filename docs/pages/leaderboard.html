Public page

Leaderboard

Weekly top players, monthly performers and the season table, ranked by MVP points, with category boards.

Purpose and access

public

Open to everyone; no login. Pages are rendered on the server on every request from the app database (never from CricHeroes directly).

URL and query parameters

URL / parameterMeaning
/leaderboard?period=week|month|seasonTab. Default month.
week=YYYY-MM-DDWith period=week: any date in the week; normalised to the Monday (IST). Options: the last 12 weeks.
month=YYYY-MMWith period=month: months since sync_start_date; default the current month.

What is shown

  • MVP ranking — top 10 by MVP points (ties broken by runs); guests badged.
  • Most runs, Most wickets (ties by economy), Most catches & dismissals, Best strike rate (minimum 30 balls) — top 5 each.
  • How MVP points work — the table from MVP_POINTS.
