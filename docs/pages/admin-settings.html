Admin page

Settings

Team and finance settings, the Google Sheet link, admins, and integration status.

Purpose and access

admin only

Admins only. proxy.ts redirects anonymous visitors to /login; the page calls requireAdmin() before loading data, and every action re-checks through adminAction().

URL and query parameters

URL / parameterMeaning
/admin/settingsNo parameters.

What is shown

  • Team & finance settings form with all keys above and an "Open sheet" link plus the service-account sharing hint.
  • Admins — list, add by email, remove (you cannot remove yourself or the last admin).
  • Integrations — whether Supabase login, photo storage, Google Sheets and the nightly cron secret are set up (yes / no only, values never shown).

Actions

Every action below is a server action wrapped by adminAction() (src/lib/action.ts): admin check → zod validation → one database transaction → audit_log entry → refresh() → Google Sheet rewrite after the response (after(() => syncSheet("change"))).

ControlServer actionWhat happens
Save settingssaveSettingsActionValidates (sheet URL must contain a spreadsheet id) and upserts settings; audit with before / after
Add adminaddAdminInserts into admins (lower-case); that person can now request a login link
Remove adminremoveAdminDeletes from admins; blocked for yourself and the last admin
