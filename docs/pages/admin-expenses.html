Admin page

Expenses & income

Team spending (balls, grounds, equipment, tournament fees, food, jerseys), other income, and the people who hold team cash.

Purpose and access

admin only

Admins only. proxy.ts redirects anonymous visitors to /login; the page calls requireAdmin() before loading data, and every action re-checks through adminAction().

URL and query parameters

URL / parameterMeaning
/admin/expenses?month=YYYY-MMFilter both lists by month.
tab=incomeOpen the Income tab first.

What is shown

  • Expenses tab — list with date, category, description, amount, paid from (holder), paid by, mode; add / edit dialog; delete with confirmation; total.
  • Income tab — sponsorship, ball sale, prize money, other; same controls.
  • Cash holders card — add a holder, rename, make default, deactivate / reactivate. Rahul is seeded as default.

Actions

Every action below is a server action wrapped by adminAction() (src/lib/action.ts): admin check → zod validation → one database transaction → audit_log entry → refresh() → Google Sheet rewrite after the response (after(() => syncSheet("change"))).

Add / edit expensesaveExpenseInsert or update expenses
Delete expensedeleteExpenseDelete row
Add / edit incomesaveIncomeInsert or update income
Delete incomedeleteIncomeDelete row

Rules and edge cases

  • Expenses and income are admin-only; they feed the fund balance and cash in hand.
  • Switching tabs does not change the URL; ?tab=income only selects the first tab shown.
